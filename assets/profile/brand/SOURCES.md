# Website brand sources

Copied from [vlachosi/ioannisvlachos.com](https://github.com/vlachosi/ioannisvlachos.com), commit `31c125e575902f56eaf573d96f2bb1c3c32345cc`.

- `mark.svg` is an unchanged copy of `assets/favicon.svg`: the hand-drawn IV monogram, fixed volatility smile, and accent dot.
- The profile header components reuse its path geometry and adapt colours using the website's `styles/light.scss` and `styles/dark.scss` palettes, as its navigation does.
- Petrona, Source Sans 3, and JetBrains Mono font files and their SIL Open Font License notices are copied from `assets/fonts/`. Embedded SVG font data keeps the banners self-contained.

The website animates/randomizes the navigation smile using JavaScript. These README images use its fixed fallback geometry, compatible with GitHub image rendering.
