# Website brand sources

Copied from the website's source repository, `vlachosi/ioannisvlachos.com`, at commit `31c125e575902f56eaf573d96f2bb1c3c32345cc`. That repository is private, so the paths below are given as plain references and are not linked.

- `mark.svg` is an unchanged copy of the circular favicon the site serves at [ioannisvlachos.com/assets/favicon.svg](https://ioannisvlachos.com/assets/favicon.svg), retrieved on 15 November 2026: the hand-drawn IV monogram, fixed volatility smile, and accent dot on a disc. It is newer than the commit above, whose favicon set the same paths on a rounded square.
- The Website button reuses its geometry. The profile header and the buttons take their colours from the website's `styles/light.scss` and `styles/dark.scss` palettes, as its navigation does.
- Petrona, Source Sans 3, and JetBrains Mono font files and their SIL Open Font License notices are copied from `assets/fonts/`. Embedded SVG font data keeps the banners self-contained. Each image embeds a subset holding only the glyphs it displays; the complete font files stay here as the source for those subsets.

The website animates/randomizes the navigation smile using JavaScript. These README images use its fixed fallback geometry, compatible with GitHub image rendering.

## Profile header

`header-*.svg` are generated by `tools/build_header.py`. The implied volatility surface is stylised, not fitted to market data, and extends the monogram's smile and accent dot over strike and maturity. In the animated files the smile draws, the surface extends from it, and the dot then falls from the top of the card, lands on the smile and slides to rest at its minimum; the path is computed in the build script from gravity and friction and played back with SVG animation, with no script. Nothing moves afterwards. The `header-static-*.svg` files show the finished state and are selected when reduced motion is preferred.
