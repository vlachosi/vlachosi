# Contact button artwork

Generated by `profile-options/tools/build_contact_buttons.py`. Each SVG embeds its fonts and icon geometry and makes no external requests. Transparent gutters (8 px on each side, 4 px above and below) space the centred buttons evenly, including when they wrap on mobile.

The `contact-*-light.svg` files use ivory backgrounds and navy labels for light pages. The `contact-*-dark.svg` files use navy backgrounds and ivory labels for dark pages. Colours come from the site's light and dark palettes in `brand_assets.THEMES`. GitHub-compatible `<picture>` sources select the files using `prefers-color-scheme`; no script or remote image service is needed. The IV and LinkedIn marks adapt to the button background, while ORCID's green and the site's SSRN blue remain unchanged.

- **Website:** the original IV monogram and volatility-smile geometry from [Ioannis Vlachos's favicon](https://github.com/vlachosi/ioannisvlachos.com/blob/31c125e575902f56eaf573d96f2bb1c3c32345cc/assets/favicon.svg), reused through `brand_assets.logo`. The navy button uses the dark mark palette, and the ivory button uses the light mark palette.
- **ORCID:** the exact inline geometry and colours of `ORCID_ICON` in the [profile generator](https://github.com/vlachosi/ioannisvlachos.com/blob/31c125e575902f56eaf573d96f2bb1c3c32345cc/scripts/profile.py). The green ORCID identifier mark is retained.
- **SSRN:** the exact inline geometry, colours and lettering of `SSRN_ICON` in the same [profile generator](https://github.com/vlachosi/ioannisvlachos.com/blob/31c125e575902f56eaf573d96f2bb1c3c32345cc/scripts/profile.py). This reproduces the site's blue SSRN badge, not a claim that it is an official SSRN logo.
- **LinkedIn:** the profile generator selects Bootstrap's `bi-linkedin` icon. The button uses the unchanged vector path from [Bootstrap Icons v1.13.1](https://github.com/twbs/icons/blob/v1.13.1/icons/linkedin.svg), coloured ivory on the navy button and navy on the ivory button. Bootstrap Icons is MIT-licensed; the complete licence follows.
- **Fonts:** Source Sans 3 labels and Petrona lettering inside the existing SSRN badge. Font files and their licences are stored alongside this document.
