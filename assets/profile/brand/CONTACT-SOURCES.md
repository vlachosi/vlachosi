# Contact button artwork

Generated by `tools/build_contact_buttons.py`. Each SVG embeds its icon geometry and the font glyphs its label uses, and makes no external requests. Subsetting the fonts needs the packages in `tools/requirements.txt`. Transparent gutters (8 px on each side, 4 px above and below) space the centred buttons evenly, including when they wrap on mobile.

The `contact-*-light.svg` files use ivory backgrounds and navy labels for light pages. The `contact-*-dark.svg` files use navy backgrounds and ivory labels for dark pages. Colours come from the site's light and dark palettes in `brand_assets.THEMES`. GitHub-compatible `<picture>` sources select the files using `prefers-color-scheme`; no script or remote image service is needed. The IV, CV and LinkedIn marks adapt to the button background, while ORCID's green and SSRN's blue remain unchanged.

The website's source repository, `vlachosi/ioannisvlachos.com`, is private. References to it below name the file at commit `31c125e575902f56eaf573d96f2bb1c3c32345cc` and are not linked.

- **Website:** the site's circular favicon (the IV monogram, volatility smile and accent dot on a disc), copied here as `mark.svg` and reused through `brand_assets.logo`. The navy button shows it in the site's own colours, an ivory disc with a navy monogram; the ivory button inverts it to a navy disc with an ivory monogram so that the disc stands out.
- **CV:** the unchanged vector paths of `file-earmark-person` from [Bootstrap Icons v1.13.1](https://github.com/twbs/icons/blob/v1.13.1/icons/file-earmark-person.svg), coloured like the LinkedIn mark. It was chosen for this button and does not come from the website.
- **ORCID:** the exact inline geometry and colours of `ORCID_ICON` in the website's profile generator (`scripts/profile.py` in the website repository). The green ORCID identifier mark is retained.
- **SSRN:** the SSRN wordmark, using the unchanged vector path from [Simple Icons v16.37.0](https://github.com/simple-icons/simple-icons/blob/16.37.0/icons/ssrn.svg) (CC0-1.0). It is set in white on a tile in `#1E4781`, the blue of the logo file Elsevier distributes, so that it reads on both the ivory and the navy button; the distributed logo itself is blue lettering on a transparent background. SSRN and its logo belong to Elsevier, which [asks that the logo not be altered](https://www.elsevier.support/ssrn/answer/can-i-use-the-ssrn-logo); it is used here only to link to the SSRN author page.
- **LinkedIn:** the profile generator selects Bootstrap's `bi-linkedin` icon. The button uses the unchanged vector path from [Bootstrap Icons v1.13.1](https://github.com/twbs/icons/blob/v1.13.1/icons/linkedin.svg), coloured ivory on the navy button and navy on the ivory button. Bootstrap Icons is MIT-licensed; the complete licence follows.
- **Fonts:** Source Sans 3 for the labels. Font files and their licences are stored alongside this document.
